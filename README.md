# RAM-Net 论文展示页

通过静态 HTTP 服务访问 `index.html`。全站使用 HTML、CSS、JavaScript、本地 SVG 和 JSON，无构建步骤、第三方依赖或在线字体。部署时保留目录结构即可：站内资源均使用相对于当前文档的路径，支持部署到子目录。第 8、9 章通过 `fetch` 加载本地 JSON，因此完整预览需要 HTTP 服务。

## 文件结构

```text
index.html                      英文论文正文、章节结构、公式和动画插入位置
assets/
  site.css                      页面排版、配色、响应式布局
  site.js                       章节导航、阅读进度、动画可见性同步
  section-scroll.js             所有章节共用的双向吸附、弹簧牵引和滚动脱离阻尼
  experiments.js                实验结果页签与键盘切换；无脚本时完整显示三张表
  embed.css                     动画的统一展示样式与播放器样式
  embed.js                      动画可见性、窄屏交互模式和 iframe 高度同步
  stage-timeline.js             sec2 / sec6 共用的带阶段名称的非均匀时间轴
  favicon.svg                   本地站点图标
animations/
  attn_cmp.{html,css,js}         注意力与存储方式对比
  ramnet_arch.{html,css,js}      RAM-Net 架构及分阶段播放器
  product_softmax.{html,css,js}  四种视图、Top-K 和分布交互
  cape.{html,css,js}             CAPE 开关、分布拖动与位置响应
  gsu.{html,css,js}              质量、门控、向量的直接交互
  cal_pipeline.{html,css,js}     CUDA 执行流水线及分阶段播放器
```

动画从原始展示页面中提取，固定配置沿用源文件默认值。移除了独立参数面板、调试区及配置导入导出；保留图内交互。`transformer.html` 未被文稿引用，因此未整合。

主页面通过 iframe 隔离各动画的变量和样式，使用消息通信同步高度。动画采用透明画布直接融入正文，不显示外围标题栏、独立底色或单独打开链接。离开可视区的动画停止逐帧绘制，并尊重系统的减少动态效果设置。小屏中的动画按可用宽度等比例缩小，无需横向滚动；sec3 选项卡移至图下方，保留适合触屏点击的尺寸。公式使用原生 MathML。

动画窗口宽度不超过 760px，或不超过 1024px 且使用粗指针触控时，自动启用简化交互：停用概率、权重、门控、质量和向量的精细编辑，保留页签、Top-K、播放和阶段切换。CAPE 和 GSU 提供独立的大按钮，主要触控目标至少为 44px；宽图可原生滑动浏览。恢复桌面尺寸和鼠标输入后，精细交互自动恢复。

每节以编号、标题和宽幅动画开场，正文、表格与公式共用对齐线。所有正文 section（包括结果章节）共用双向吸附：接近顶部对齐位置时由阻尼弹簧轻柔牵引；停稳后吸收滚轮和触控板的惯性余量，持续滚动或明确滑动即可脱离，离开后暂不回吸。动画 iframe 内的滚动也接入同一逻辑，保留图内操作。若标题与动图无法完整放入当前视口，则优先对齐动图顶部，避免导航遮挡。章节导航使用同一对齐位置，键盘翻页可直接脱离；减少动态效果模式下关闭牵引与阻尼。

sec2 和 sec6 将精简后的阶段名称居中放入进度条，不显示阶段编号、时间、Loop 或倍速选项，暂停图标使用 SVG 双竖线。桌面进度条高 34px，分段宽度按 65% 均分、35% 实际时长混合分配。指示线在各段内按真实时长移动；桌面可拖动定位，手机将阶段排成三列，保留 44px 点击高度、各段进度填充和点击跳转。

sec5 的四阶段进度条位于画布下方，保留阶段颜色、进度填充和点击跳转；动画使用完整画布宽度，手机阶段按钮排成两列，无需横向滑动。

正文已静态写入 `index.html`，直接在该文件中维护。首屏提供 [arXiv 论文链接](https://arxiv.org/abs/2602.11958)，GitHub 和 Hugging Face 暂以不可点击的 “Coming soon” 入口占位，待补充实际地址。作者和机构尚未添加。

实验区收录提供的三张结果表：语言建模与推理、S-NIAH 1K–16K 检索、FDA / SWDE / NQ 等任务，共 33 行模型结果、440 个数值，覆盖 340M 与 1.3B。数据直接保存在 HTML 中，保留原表精度与平均值；粗体表示同规模下最优任务分数（含并列），天蓝底色标出 RAM-Net。第三组沿用原始任务缩写与 512 / 1K / full 标记。原有 128K 检索和速度结果另列为独立实验设置。

## 验证

已使用本机 Chrome 动态检查：1440、768、390 和 320px 布局，原有六个动画的阶段跳转、时间轴、Top-K 边界值、CAPE 开关、分布键盘操作与鼠标拖动、离屏暂停，以及减少动态效果设置。新增两个探针动画已检查共 128 条 trace 的切换和桌面、390px 窄屏布局。完整站点需通过 HTTP 服务加载八个动画及三个探针 JSON 文件。

已验证多层子目录部署：八个动画及三个 JSON 文件均成功加载，35 次资源请求全部位于该子目录内，无根目录依赖或资源加载失败。直接双击文件产生的 `file://` 页面受浏览器本地文件读取限制，不适合预览 JSON 驱动的动画。
