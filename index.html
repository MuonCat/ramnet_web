The idea, in brief

RAM-Net separates memory capacity from per-token access. It stores history in a fixed-size array of addressable slots, while each token reads and writes only a small subset. More slots provide room for more information without a full-state scan at every step. Sparse access keeps sequence processing linear in length and confines direct write interference to shared slots.

01The memory question

More Memory, Less State Access

A sequence model needs to store information and retrieve it when it matters. Memory capacity and access cost are separate concerns: a larger memory is useful only if the model can find the right information efficiently.

Full attention keeps a key–value entry for every token and retrieves values by comparing their keys with the current query. This supports precise retrieval, but the cache and per-step access cost grow with the sequence.

Linear attention compresses history into a fixed-size recurrent state. Storage and per-step computation stay constant as the sequence grows, but superposed contributions can interfere and make individual facts harder to retrieve.

RAM-Net organizes its recurrent state into addressable slots. Each token reads or updates only a few slots, so memory capacity can grow without scanning the entire state.

Writes can still collide when they select the same slot. Increasing the slot count gives the model more room to separate information without a proportional increase in per-step state access.

02Inside RAM-Net

Reading and Writing a Small Part of Memory

Each token produces a key to select write locations, a query to select read locations, and a value to store.

The Address Decoder maps the key and query to weighted slot addresses. Gated Sparse Update modifies the selected write slots. The read path combines the selected contents, then applies normalization, an output gate, and a linear projection.

Read and write addresses may differ. Slots outside the write set remain untouched.

Two quantities control the design: the total slot count M sets memory capacity, while K sets how many slots each read or write accesses. Both stay fixed as the sequence grows for a given model configuration.

The remaining challenge is to select useful addresses without scoring every slot.

03Product Softmax

Product Softmax: Many Slots, Few Logits

Product Softmax constructs a large address distribution by multiplying small component distributions.

Four address components with four choices each define 44 = 256 slots. Four small softmax operations need just 16 logits to describe a distribution over all 256.

The weight of a complete address is the product of the corresponding weights in its components. More generally, U groups with dp choices each represent M = dpU slots using only U dp logits.

Soft Radix Address

Replace each fixed address digit with a distribution. Each combination of digits identifies a slot, and the product of their probabilities gives its access weight. A soft address can therefore assign weight to several slots at once.

Multilevel Decision Tree

Each tree level represents one address component, and each root-to-leaf path represents a slot. Its weight is the product of the branch weights. Sharing the same component distribution across a level makes the highest-weight paths efficient to find.

Joint Distribution

Each slot is a point in a four-dimensional address lattice, with one coordinate from each factor. Fixing one factor value selects a 64-slot slice: that value is broadcast across the slice and multiplied by the other three factors to determine each slot's weight.

The rotating projection uses three coordinates for position and the fourth for cube scale. Color strength represents the joint weight; the highlighted slice shows where the active factor value contributes. Black outlines mark the Top-K slots.

Regroupable Address

The product structure lets us regroup factors without changing any slot weight. View A combines factors 1–3 into a 64-way row coordinate, with factor 4 selecting one of four columns. View B uses factor 1 for four rows and combines factors 2–4 into 64 columns.

The same address sequence scans both the 64 × 4 and 4 × 64 arrays, tracing different spatial patterns. These are two views of one address space: every slot keeps its weight, and the same Top-K slots retain their black outlines.

Waveform Modulation

In slot-index order, each address component forms a repeating, piecewise-constant waveform. Higher-order digits select broad regions; lower-order digits vary over shorter intervals. Their pointwise product produces the final distribution.

All five views describe the same distribution. RAM-Net builds addresses one component at a time, retaining only the Top-K candidates at each step. This finds the final addresses without materializing the full M-dimensional distribution.

04Position-aware addresses

CAPE: Position-Aware Memory Access

Content identifies what to retrieve. Position tells the model how far that information lies from the current token.

Cyclic Address Positional Embedding (CAPE) shifts read and write addresses around the slot array according to token position. Address overlap then reflects both content and relative distance.

Repeated writes of the same content trace a cyclic path through memory. Shifting the current read address in the same way makes matching sensitive to the distance between the read and the earlier write.

CAPE shifts slot indices while keeping access sparse. RAM-Net combines position-sensitive heads with content-only heads to capture both relative-position patterns and associations that hold across positions.

05Gated Sparse Update

GSU: Balancing Retention and New Information

Each new write poses a choice: how much of the slot's history should remain, and how strongly should the new value change it?

Gated Sparse Update (GSU) maintains content s and retained write mass m for each slot. Larger mass makes the content harder to change. The forgetting gate reduces that mass, giving the incoming write more influence.

For slot a at step t, let wt(a) be its write weight, vt the incoming value, and γt the forgetting control. A small ε stabilizes the update rate. The update has four steps.

αt(a)=σ(logit(1−wt(a))−γt) mt(a)=αt(a)mt−1(a)+wt(a) ηt(a)=wt(a)mt(a)+ε st(a)=st−1(a)+ηt(a)(vt−st−1(a))
  1. Retention (α). The sigmoid sets how much of the previous mass survives. A stronger write or larger γt lowers this fraction.
  2. Mass (m). Keep the retained previous mass, then add the current write weight.
  3. Update rate (η). Divide the write weight by the new mass plus ε. This keeps the denominator nonzero and controls the new value's influence.
  4. Content (s). Move the old slot content toward vt by that rate: a small rate preserves more history, while a rate near 1 lets the new value dominate.

For an unselected slot, wt(a) = 0, the retention factor is 1, and the update rate is 0. Both content and write mass stay unchanged. GSU confines forgetting and updating to the selected write slots, allowing frequently used slots to adapt while preserving untouched memories.

06Sparse access on the GPU

CUDA: Parallel Work Across Memory Slots

Sparse access reduces memory traffic. To turn that saving into efficient GPU execution, RAM-Net organizes work around independent memory slots.

During training and prefill, the model computes Top-K addresses across tokens in parallel, then groups read and write events by slot. Each slot receives its own sequence of access events.

Different slots and their channels can run in parallel, while events within each slot preserve the causal order required by the recurrence. Slots with no events require no work.

During autoregressive decoding, the model directly accesses the slots selected by the current token. It does not scan the full recurrent state.

At 340M, Top-8 accesses 0.4M of 26.2M state elements—about 1.5% of its total state and roughly 1/32 of Mamba2’s 12.9M active state. At 1.3B, Top-8 accesses 0.8M of 52.4M elements; the same Top-K accounting gives 1.6M active elements for Top-16. These figures measure state access; decoding throughput is evaluated separately.

What changes with Top-K?

At 340M, moving from Top-8 to Top-32 increases active state from 0.4M to 1.6M elements while total state stays at 26.2M. S-NIAH average improves from 64.7 to 72.9, and the additional-task average from 23.2 to 32.0. The trade-off is better results at a higher per-token access cost.

Beyond these tables

The paper also evaluates fine-grained associative recall on MQAR and longer-context retrieval in a separate S-NIAH-1 setting. With repeated filler, the 340M Top-8 model reaches 99.4% at 128K after training at 4K. That setting is distinct from the 1K–16K comparison above.

Separate 340M-scale decoding benchmarks on a single NVIDIA RTX 5090 report throughput comparable to GLA and higher than the tested Mamba2, DeltaNet, and Gated DeltaNet implementations. Runtime depends on the implementation and hardware as well as state access.

Retrieval still depends on reliable address selection: an unselected slot cannot contribute to the current read. More slots increase capacity; a larger Top-K increases access. Their benefits depend on the task.

09Head probes

What Do Shared Addresses Reveal?

Selected heads show shared write–read addresses between adjacent word pieces, or between opening and closing punctuation. The history matrix exposes these connections token by token; the slot view follows how information from the source token is retained and read.

These are exploratory patterns in selected heads and short texts. Address overlap offers a useful window into memory use, but does not by itself establish semantic matching or a causal role in the model’s output.
